运行服务器

新服务器接入说明

下载节点包，上传新服务器，在 Ubuntu / Debian 执行：

mkdir -p ~/tgpanel-node-setup
tar -xzf ~/tgpanel-node.tar.gz -C ~/tgpanel-node-setup
sudo bash ~/tgpanel-node-setup/node_install.sh

仅允许主面板 IP 访问新服务器 9443 端口，填入安装结果中的地址、密钥与指纹。设为新增默认后，新机器人在此运行。

🆕 添加与激活机器人
管理员：在「新增机器人」选择类型，填写客户 Token 和使用时长。验证成功后，将激活码发给客户。
客户：私聊自己的机器人发送 /admin 激活码，收到绑定成功提示后开始使用。
记账机器人：每个机器人拥有独立源码、配置和数据，默认使用最新功能；客户在 Telegram「配置中心」管理自己的机器人。

    


    

      📒 记账机器人
      

        进群准备：@BotFather → /mybots → 选择机器人 → Bot Settings → Group Privacy → Turn off；已有群需移出后重新加入机器人。

        记账：+100 入款、-50 冲减入款。只有开头为 + 或 -、后面跟数字金额的消息才记入款；13-17的、张三+100 不记账。

        单笔参数：+1000/7.3 指定汇率；+1000*0.12 本笔费率12%；+1000u 入款1000U，不扣入款费率。参数仅影响本笔。

        下发：下发100 记100U，下发-100 冲回；开启纯U模式后使用 分红100。

        查账：账单、昨日账单、完整账单、显示日切。回复原记账消息发送 撤销；清空 需管理权限。

        配置：私聊「配置中心」。基础配置用于新群，现有群在「群组」修改；个人参数优先于群默认，仅影响新流水。拥有者在「内部人员」授权。

        完整说明：私聊「📖 使用说明」，按九个分类查看命令；账单默认简洁模式，可在账单底部切换详细。

    


    

      📜 消息记录
      

        查看：选择记账机器人 → 会话 → 消息。支持搜索、图片预览及被回复消息引用；点击引用可定位原消息。

        记录范围：默认开启，仅保存机器人实际收到的消息，保留48小时；不追溯历史消息。会话可单独关闭记录。

        提醒：未读数量显示在会话旁，新消息自动更新。记录存储在运行面板的服务器。

    


    

      📨 客服机器人
      

        使用：激活后，客户私聊消息会转发给你。回复这条转发消息，内容会发送给对应客户。

        指令：/list 最近客户；/help 全部指令。请保持 Telegram 正常登录，避免屏蔽机器人。

    


    

      💰 USDT 助手
      

        查询：发送完整 TRC20 地址，查询余额与近期转账；「查U汇率」查看实时报价。

        监听：/watch 地址 备注 添加监听，在「地址管理」查看或删除。

        范围：监听符合条件的普通转账；新增监听先建立基线，历史交易不会推送。

    


    

      🛒 商城机器人
      

        配置：机器人列表 → 配置，填写收款地址、单价、每单位能量及上游 API Key，再测试连接。

        购买：客户私聊「⚡ 充能量」，按说明从自己的钱包转TRX；能量发到付款地址。请勿直接从交易所付款。

        订单：查看收款与发货状态；失败订单可重发。重发前确认上游未发货，避免重复处理。

    


    

      ❓ 常见问题
      

        群内记账无响应：检查群授权、记账开关及 Group Privacy；隐私关闭后，已有群需重新加入机器人。

        机器人无响应：检查启用状态、到期时间和运行日志，再使用「重启」。

        消息记录缺失：仅记账机器人提供记录；检查会话开关、隐私设置和48小时保留期限。

        更换Token或续期：在机器人列表使用「Token」或「续期」。商户续期请联系管理员。
