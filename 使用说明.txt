========================================
 TG 客服机器人 · 多开管理版
 一个后台跑多个机器人，网页面板管理
========================================

【它是做什么的】

  你（管理员）打开网页面板
      → 填「备注 + 机器人 token」→ 点添加
      → 面板生成一个【绑定码】
      → 你把绑定码发给朋友
      → 朋友在自己 Telegram 里给机器人发： /admin 绑定码
      → 面板显示「已绑定」，这个机器人开始工作

  之后：客户私聊那个机器人 → 消息转到朋友自己的 Telegram 私聊
        朋友回复那条消息 → 自动发给对应客户


----------------------------------------
机器人时长 / 到期 / 恢复
----------------------------------------
添加机器人的时候，可以选一个时长档位：

    1 天 / 1 个月 / 3 个月 / 半年 / 1 年 / 永久

【到期会怎样】
到期那天，机器人自动【停用】—— 客户和操作人都用不了，
面板上显示红色「已到期」。

【到期后机器人还会回话】
到期后机器人不会直接「装死」，有人发消息它会回：

    ⏰ 机器人已到期
    请及时续费。
    7 天内未续费，数据将被删除。

★ 但两种机器人回法不一样：

  【USDT 助手】
   谁发消息（你、操作人、陌生人）→ 都收到那条到期提示。

  【客服机器人】
   · 你或操作人发消息 → 收到到期提示
   · 客户发消息 → **客户收不到任何回复**（不让客户知道你欠费），
     改成给你（绑定者）发一条提醒：
       ⚠️ 有客户给机器人发消息了，但机器人已到期，
          消息没能转给你。
       客户：客户甲
     ★ 提醒只发给绑定者，操作人不会收到。
     ★ 同一个客户半小时内只提醒一次，不会刷屏。

【7 天恢复期】
停用后开始倒计时 7 天。这期间你在面板上点「续期恢复」，
选一个时长，机器人立刻活过来。
★ 续期是从「点续期的那个时刻」重新算，不是从原来到期日接。

【7 天没处理会怎样】
会自动【彻底删除】—— bots.json 里的记录和客户数据一起清掉，
不可恢复。所以面板上会显示「还剩几小时删除」，别忘了看。

【在面板哪里看】
机器人列表多了一列「到期」：
    永久              —— 不会过期
    剩 30 天（绿）    —— 还早
    剩 2 天（黄）     —— 快到了
    剩 8 小时（红）   —— 今天到期
    已过期 / 3 天后删除（红） —— 在恢复期里

【怎么续期】
点那一行的「续期」按钮 → 弹窗选时长 → 确定。
已到期的机器人不能点「启用」复活，只能走「续期恢复」。

★ 检查频率：程序每 5 分钟扫一次，所以到期可能会有最多 5 分钟延迟。


----------------------------------------
怎么启动
----------------------------------------
双击「TG客服多开版.exe」

会自动弹出命令行窗口 + 打开浏览器面板。
窗口里会显示：

    面板地址：http://127.0.0.1:8080
    面板密码：TKGZ8CGL          ← 以你窗口里显示的为准

★ 这个黑窗口不能关，关了所有机器人和面板都停。


----------------------------------------
给朋友开一个机器人（3 步）
----------------------------------------
★ 朋友不会建机器人？面板里有个「📖 新手教程」，
  点一下「复制整段教程」发给朋友，他照着做就行。
  教程里把 @BotFather、/newbot、怎么拿 token、怎么发绑定码
  全写清楚了，不用你自己解释。

【第 1 步】朋友去 @BotFather 建一个机器人
   1. Telegram 搜 @BotFather → 发 /newbot
   2. 起名字、起用户名（必须 bot 结尾）
   3. 拿到 token（形如 1234567890:AAHxxxx...）
   4. 把 token 发给你

【第 2 步】你在面板里添加
   1. 打开面板 http://127.0.0.1:8080
   2. 输入面板密码进入
   3. 「添加机器人」那里填：
        备注：张三-售后          ← 自己看得懂就行
        token：1234567890:AAH...  ← 朋友给你的
   4. 点「添加」
   5. 列表里出现这个机器人，有一列【绑定码】，点一下就能复制

【第 3 步】把绑定码发给朋友，让他绑定
   直接把复制到的内容发给朋友，长这样：
        /admin 换成你自己的
   朋友在他自己的 Telegram 里，打开那个机器人，把这条发过去
   机器人回「✅ 绑定成功」，面板上那一行就会变成绿色「已绑定」


----------------------------------------
USDT 助手怎么用
----------------------------------------
这是给你自己用的：查 U 交易、监听地址、查实时汇率。

【添加】面板「添加机器人」那里，类型选「USDT 助手」，
        填个备注（比如：我的收款），token 填机器人的 token。
        （去找 @BotFather 建一个新机器人，步骤见上面的新手教程）

【绑定】和客服机器人一样：把生成的绑定码发给自己，
        在 Telegram 里给这个机器人发 /admin 绑定码

绑定成功后，机器人会带出底部菜单，五个按钮：

  📡 地址监听   —— 加地址进监听，有进出账通知你
  🔍 查U交易    —— 查地址的余额和交易（只查，不监听）
  💱 查U汇率    —— 买 U 最划算的 TOP10
  🗂 地址管理   —— 看所有监听地址，点按钮删除
  👥 操作人     —— 让别人也能用这个机器人（见下面单独一节）

★ 如果底部没看到菜单，给机器人发一次 /start 就会出来。

★★ 重要：先点按钮选功能，再发地址 ★★
   机器人的菜单是「模式」式的：
   点了「📡 地址监听」，接下来发的地址就是去加监听；
   点了「🔍 查U交易」，接下来发的地址就是去查询。
   两个功能互不干扰，各干各的。

———— 📡 地址监听 ————
1. 点「📡 地址监听」
2. 发一个 TRC20 地址，例如：
       TNXoiAJ3dct8Fjg4M9fkLFh9S2v9TXc32G
3. 机器人回「✅ 已加入监听」，**只做这一件事，不查任何东西**
4. 然后它会问你要不要加备注：
       · 想加 → 直接回复昵称（例：客户A付款）
       · 不加 → 回复「无」
   加完备注就结束了，不会再多问。
   想继续加地址，直接发下一个地址即可，不用再点按钮。

之后这个地址有转入或转出，机器人立刻通知你，内容包括：
    金额、方向、对方地址、备注、时间、交易哈希、
    最新余额、区块浏览器链接

★ 第一次加监听，机器人会先"建基线"（记住当前已有的交易），
  只通知之后新发生的交易，不会把历史记录全推给你。

———— 🔍 查U交易 ————
1. 点「🔍 查U交易」
2. 发一个 TRC20 地址
3. 返回：USDT 余额、TRX 余额、最近 10 条转账记录

★ 只查询，**不会**把地址加进监听。

———— 💱 查U汇率 ————
点按钮，或者发 /rate。

数据来自【欧易 OKX 场外商家的实时挂单价】，
列出买 U 最划算的 TOP10：第几名、价格、商家名。

底部还会标出：
    📍 最低价      最便宜的那家
    📌 第三档汇率  第 3 家的价格

价格保留 2 位小数。有 1 分钟缓存，点太快不会重复请求。

———— 🗂 地址管理 ————
点开后列出所有正在监听的地址，
每个地址下面有一个「🗑 删除」按钮，点一下就删掉，
列表会自动刷新。

———— 👥 操作人（让多人共用一个机器人）————
一个机器人可以让几个人一起用，不用每人建一个机器人。

【怎么加人】
1. 绑定者点「👥 操作人」→ 点「➕ 添加操作人」
2. 输入对方的 Telegram 用户名，例：@zhangsan
3. 机器人会给你两种方式，任选一种让 TA 通过：

   方式一（推荐，最快）：
       机器人给你一条专属链接，形如
       https://t.me/你的机器人?start=op_a1b2c3
       把这条链接转发给 TA，TA 点一下就通过了。

   方式二：
       让 TA 直接给机器人发任意一条消息，就会自动通过。

★ 为什么不能直接添加？因为 Telegram 不允许机器人用用户名
  反查用户，机器人只能认出「跟它说过话的人」，所以要走上面一步。
★ 链接是一次性的，用掉就失效。
★ 被添加的人和你一样，能用这个机器人的全部功能。

【怎么看/踢人】
点「👥 操作人」能看到所有使用者列表，每个操作人下面有「🗑 移除」按钮。
绑定者不能被移除（只有绑定者能管操作人，操作人不能管别人）。

【权限说明】
· 绑定者：全部功能 + 管操作人
· 操作人：全部功能，但不能加人/踢人


———— 其他 ————
    /ops              操作人管理（同「👥 操作人」）
    /watch 地址 备注  直接加监听（带备注，不用走上面流程）
    /unwatch 地址     取消监听（也可以在地址管理里点按钮）
    /id               看你的 Telegram ID
    /help             看全部指令

★ 这个机器人只读公开的链上数据，不碰私钥，也不能转账。


----------------------------------------
面板上每个按钮什么意思
----------------------------------------
【绑定码】     点一下自动复制（连 /admin 一起带上，直接发给对方即可）
【使用者】     ⏳等待绑定 = 对方还没发绑定码；✅已绑定 = 已经在用了
【状态】       ● 运行中 = 正常；冲突 = 这个 token 在别处也在跑，要关掉一个
【客户】       这个机器人一共有多少个客户联系过
【停用】       临时停掉，客户消息不再转发（数据保留）
【启用】       重新开起来
【换绑定码】   解除当前使用者，换一个新码给别人用
【删除】       彻底删除，客户数据一并清除（不可恢复）


----------------------------------------
数据隔离
----------------------------------------
每个机器人是独立的：
  ● 独立的数据文件 data/<机器人ID>.json
  ● 独立的管理员（谁绑定的谁收到消息）
  ● 独立的客户列表和拉黑名单

张三的客户消息只会发到张三那里，李四看不到；
你的面板只能看到「有多少个客户」这个数字，
看不到具体的聊天内容。


----------------------------------------
常见问题
----------------------------------------
Q：朋友说发了绑定码没反应？
A：检查三件事：
   1. 黑窗口是不是还开着
   2. 绑定码有没有复制错（区分大小写，直接复制面板上的）
   3. 面板上「状态」是不是「● 运行中」，如果是「冲突」，
      说明这个 token 在别的地方也开着程序，关掉另一个

Q：状态显示「冲突」怎么办？
A：同一个机器人 token 不能同时被两个程序使用。
   常见原因是：你之前那个单机版「TG客服机器人.exe」还开着。
   关掉它，然后在面板点「停用」再「启用」即可。

Q：朋友那边收不到客户消息？
A：让朋友检查：
   1. 有没有绑定成功（机器人回「✅ 绑定成功」）
   2. 有没有把机器人拉黑或删掉对话

Q：关掉窗口后还能用吗？
A：不能。这个程序必须一直开着。要 24 小时在线，
   需要放到服务器上跑（到时候把整个文件夹拷过去，
   双击 exe 或配成开机自启）。

Q：怎么改成 24 小时 / 放到服务器？
A：编辑 config.json：
     "host": "0.0.0.0"    ← 改成这样，外网才能访问面板
     "port": 8080         ← 端口，按需改
   ★ 改成 0.0.0.0 后，面板密码就是唯一防线，千万别告诉别人！

Q：之前单机版的机器人怎么没了？
A：已经自动迁移过来了，备注叫「我自己的客服」，
   绑定码和你的绑定状态都保留着。
   ★ 单机版（桌面\TG客服机器人）不要再开了，会和新版冲突。


----------------------------------------
注意
----------------------------------------
● bots.json 里有所有机器人的 token，相当于一堆密码，别外发
● 上服务器后，config.json 里的密码一定要自己改复杂一点
● 换电脑 / 上服务器：把 exe、config.json、bots.json、data 文件夹
  一起拷过去
● 客户数据可以用面板看数量，具体聊天记录在 data/<id>.json 里
