群记账机器人 · 使用速查

开始使用
1. 私聊机器人发送 /admin 激活码，完成绑定。
2. 添加机器人进群，授予所需权限；普通消息接收需正确设置群隐私。
3. 需要关闭 Group Privacy 时，在 BotFather 设置后移出并重新加入群。
4. 私聊点击「配置管理」，设置群参数并授权操作人。

常用记账
+1000             入款 1000，使用个人参数或群默认。
+1000/7.3         本笔汇率 7.3；RMB入款除以汇率结算U，U入款乘以汇率结算RMB。
+1000*0.12        本笔费率 12%；*3 表示 3%。
+1000*-5          本笔返佣 5%。
+1000u            入款 1000 USDT，不扣入款费率。
+1000 备注        带备注入款；回复人员消息可归到被回复人。
-1000             冲减入款。
下发100           按本群结算币种记账下发100：RMB入款群下发U，U入款群下发RMB；不执行真实转账。
下发-100          按本群结算币种冲回下发100。明确写「下发100u」则按100U记录。
历史下发保留原币种；显示为RMB时按该笔保存的汇率折算，不随新汇率变化。
切换群入款模式仅影响新流水；每笔保存记账时的结算模式，回复修改沿用原币种与原汇率。
同一账期有两种模式时，入款按原币种列出，下发金额按U、RMB分别汇总，不互相折算相加。
未保存模式的旧入款按原始币种恢复：RMB入款结算U，U入款结算RMB；纯U／分红模式仍结算U。

账单与修改
账单 / 昨日账单 / 完整账单：查看对应账期。
/我：查看个人账目；/统计：拥有者私聊查看人员汇总。
撤销：回复原记账消息或回执；不要只发送无目标的撤销。
修改：回复原记账消息发送新金额，按提示确认。
清空：清空当前群账目；需要留存时先开启清账存档。

群参数
设置汇率7.3 / 设置费率3：设置本群默认值。
设置汇率 @用户名 7.3：设置本群个人汇率。
设置费率 @用户名 默认：恢复该项群默认。
设置实时汇率：同步当前群报价。
设置日切时间3 / 关闭日切 / 显示日切：管理北京时间日切。
上课 / 下课：开启或暂停记账。
设置全员 / 取消全员：拥有者或内部成员开关本群全员记账。

小程序
概览：欢迎语、人员、功能开关、广告、回复和地址查询。
用户：个人参数；群组：群参数与群操作人。
账单：群组 → 账期 → 流水；计算过程点击「计算明细」。
统计：本月自然日；清空计入、撤销不计、结转不重复计入。

群发广播
私聊发送「广播」→ 发送内容 → 广播预览 → 选择目标群（支持全选）→ 下一步 → 确认发送或取消。
发送文字、单张图片，或在图片说明中填写文字后一起发送；说明最多 1024 字符。
核对预览和目标群后点击「确认发送」；发送前可取消。
图片请按照片发送，不要合并为相册或作为文件发送。
图片、预览说明及按钮在同一条消息中显示；正文用上下横线分隔，不显示「广播内容：」。有图片时，在正文上方显示「🖼️ 已附图片」。
图片说明接近1024字符上限时，优先完整显示正文；确认按钮同时显示目标群数量。
发送结束后原来的「正在广播」直接更新为完成结果，取消或完成后清除操作按钮。
按钮只在小程序「配置中心 → 广播按钮模板」配置，广播聊天中不提供配置入口。
默认不使用按钮。新增模板后填写按钮文字和完整的 http:// 或 https:// 链接；点「向右增加按钮」在右侧插入按钮，点「向下增加按钮」插入新一行，每行最多3个。
配置时实时预览排列；最多保存20套模板，每套最多6行，每个按钮文字最多64字符。
保存后点击「用于广播」，之后新建的广播会带上所选模板；点击「不使用按钮」可关闭。
修改或删除模板不影响已经进入预览的广播。删除使用中的模板后，新建广播恢复不带按钮。
管理或广播权限人员可维护本机器人的模板；已确认升级的群只显示升级后的群，旧群不再参与广播。

使用边界
- 默认仅授权人员可记账；设置全员仅对当前群生效。
- 新参数只影响后续流水，历史金额不重算。
- 纯U／分红模式仅无历史账目时可切换，以页面提示为准。
- API Key 仅用于查询；不要填写钱包私钥或助记词。
- 完整命令与工具说明见机器人底部「使用说明」。
