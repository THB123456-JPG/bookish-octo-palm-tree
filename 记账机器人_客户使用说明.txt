群记账机器人 · 使用说明
========================================

【第一步 · 必须先做，否则记账功能等于废的】

去 BotFather 关掉机器人的“群消息权限”：

  1. Telegram 里搜 @BotFather，打开对话
  2. 发送 /mybots
  3. 点你那个机器人
  4. 点 Bot Settings
  5. 点 Group Privacy
  6. 点 Turn off  （要看到变成 "Privacy mode is disabled" 才算成功）

★ 为什么要做这一步：
  Telegram 默认不让机器人看群里的普通聊天，只让看 @它 和 /命令。
  不关的话，群里发 +100 机器人根本收不到，一笔都记不上。

★ 关完之后还必须做这个：
  把机器人【踢出群】，再【重新拉进群】一次。
  不重拉的话，老的权限设置会一直生效，等于白关。

----------------------------------------

【第二步 · 把机器人拉进群】

  1. 把机器人拉进你的记账群
  2. 进群后发一条消息（随便发什么都行），让它认识这个群
  3. 建议给机器人管理员权限：
     群里点机器人名字 → 点“提升为管理员”
     建议勾上【删除消息】（群管理里的“清理消息”要用）

  谁把机器人拉进群的，谁就是这个群的“群主”，可以管设置。

----------------------------------------

【第三步 · 群里怎么记账】

  入款           +100          记一笔 100
  带人名         +100 张三     记一笔，备注是张三
  减分           -50           记一笔 -50（比如退钱）
  回复记账       回复某人消息后发 +100   → 记到那个人头上

  看账
    账单              今天的账（带按钮：今日 / 昨日 / 简洁 详细）
    昨日账单          昨天的账
    完整账单          全部账

  看我自己的账       发：/我
    → 只列【你自己】记的账（别人记的一条都不会显示）
    → 每条带算法，比如 100/6.67=14.99U，跟账单里对得上
    → 最后给合计：共几笔、加分多少、下发多少
    谁发的 /我 就统计谁，群里所有人都能用

  记错了要改
    撤销              注意：不是直接发“撤销”就行，有两种用法：
                       ① 回复那条记账的消息，再发“撤销”
                       ② 或者带上编号：撤销 #5
                       编号就是账单里每条前面的那个 #数字
    清空              把本群流水全部清掉（要群主或操作员才能用）

----------------------------------------

【设置 · 在群里发消息就行】

  开启 / 开启记账 / 上课      开始记账
  关闭记账 / 暂停 / 下课      停止记账（之前的记录还在）

  汇率 7.2              设置汇率（1 U = 7.2）
  设置汇率 7.2          一样的
  设置实时汇率          自动去欧易抓实时价
  币价                  看看现在什么价
  查看费率              看当前汇率和费率
  设置费率 10           手续费 10%
  费率 10               一样的

  日切 3                每天凌晨 3 点切账期（北京时间）
  设置日切 3            一样的
  查看日切              看当前设置和下次切账时间

----------------------------------------

【给群里的人开权限 · 在群里操作】

  回复某人的消息，发：添加权限   （或者发：添加操作员）
  回复某人的消息，发：删除权限   （或者发：删除操作员）
  操作员                        看当前有权限的人

  有权限的人才能改汇率、费率、日切，才能清理消息、@全体。
  群主（拉机器人进群的人）默认就有权限。

----------------------------------------

【群管理】

  @全体
    通知所有人 今晚8点结算
    通知所有人                 （不带内容就只 @ 人）
    @全体 今晚8点结算         一样的
    说明：只能 @ 到群里发过言的人。5 分钟内只能 @ 一次（防刷屏）。

  清理群里没用的消息
    群里直接发：/del
    说明：只删得掉 48 小时以内的消息，更早的 Telegram 不让删。
          机器人必须有【删除消息】权限。

  群成员
    群成员                    看群里有多少人、多少人最近活跃

----------------------------------------

【私聊机器人 · 只有你能用】

  广播
    私聊机器人发：广播
    → 勾选要发哪些群 → 点“下一步” → 输入内容 → 点“确认发送”
    一句话带内容也可以：广播 今晚维护，暂停接单

  批量清理
    私聊机器人发：/del
    → 勾选要清理的群 → 下一步 → 确认清理

  使用说明
    私聊机器人发：/使用说明    随时看命令大全

  跨群统计自己的账
    私聊机器人发：/我
    → 弹出群列表，点一下打勾（可以多选，也可以直接点“全选”）
    → 点“下一步”，每个群给一段明细，最后给总计
    只有机器人主人和操作员能用；统计的还是【你自己】记的账

----------------------------------------

【查U · 监听地址进出账】

  ★ 这个功能是【私聊机器人】用的，不是群里（群里发地址是核对图，见下面）

  查余额和最近交易
    私聊机器人，直接发一个 TRC20 地址
    → 先回一句“⏳ 正在查询…”，查完自动改成一张卡片
    → 卡片上有：TRX / USDT 余额、最近 20 笔 USDT 转账（转入/转出都列）
    查一次大概几秒。想看哪个就发哪个，发一个查一个，不会拦你。

  盯着这个地址
    在卡片上点「📡 加入监听」
    → 以后这个地址【每一笔已确认的转入/转出】都会私聊通知你
    → 通知里带：金额、币种、转入还是转出、
       ★付款方地址（钱从哪来）和收款方地址（钱到哪去）★
       —— 对账就看这两个，光有金额没用
    → 点通知上的「链上交易详情」能看到这笔的链上记录

  只想要一部分提醒？
    地址簿 → 点那个地址 → 可以改：
      · 只看哪个币（USDT / TRX）
      · 只看转入，或只看转出，或都看
      · 低于多少钱的不提醒

  ★ 提醒发不出去会怎样
    不会当作“已经通知过”。机器人会过一会儿再试一次，
    直到发出去为止 —— 不会让你漏掉一笔钱的提醒。
    （如果一直收不到，检查一下你有没有屏蔽机器人。）

  ★ 查不动 / 提示“限流”怎么办
    链上接口是公共的，用的人多的时候会限流。想查得更顺，
    可以去 TronGrid 官网免费申请查询用的 Key：
      1. 电脑上打开 https://trongrid.io/ 注册
      2. 在控制台（Dashboard）的 API Keys 页面建一个 Key
      3. 复制那串 Key，私聊发给机器人，或者发：
           设置密钥 你的Key

    ★ 建议一次多建几把（比如 3 把），然后这样加：
           设置密钥 第一个Key
           添加密钥 第二个Key
           添加密钥 第三个Key
      最多能存 5 把。机器人会【轮着用】——
      某一把被限流了，下一次查询自动换另一把，不用干等。
      看现在配了几把：发「密钥列表」（只显示后 4 位，不会把 Key 显示出来）

    机器人会先真查一次确认这个 Key 能用，能用才保存；
    ★ 保存前它会把你那条带 Key 的消息删掉（免得一直躺在聊天记录里）。
    想换掉全部：发「设置密钥 新的Key」就覆盖了。
    全部不要了：发「设置密钥 清空」。

    ★★ 那只是【查询用的 Key】，不是钱包私钥。
       任何情况下都不要把钱包私钥、助记词发给任何人（包括机器人）。

----------------------------------------

【实用小功能】

  发 TRC20 地址 → 机器人回一张“防篡改核对图”
    转 U 之前发给对方核对，防止地址被木马换掉

  发算式 → 直接出结果
    比如发：1+2*3    回 9

【常见问题】

Q：群里发 +100 机器人没反应？
A：99% 是 Group Privacy 没关，或者关了没把机器人踢出去重拉。
   回去看【第一步】。

Q：机器人不回消息？
A：① 群里发一条消息试试，让它先认识这个群
   ② 检查机器人是不是被停用了
   ③ 重启一下机器人再试

Q：/del 清理没反应？
A：机器人要有【删除消息】权限。群里点机器人名字 → 提升为管理员 → 勾“删除消息”。

Q：@全体 只能 @ 到一部分人？
A：Telegram 限制，只能 @ 到在群里说过话的人。没说过话的 @ 不到。

Q：能 @ 到全群吗？
A：Telegram 机器人做不到 @ 真正的“全体成员”（那是群主手动能用的）。
   本机器人是 @ 所有发过言的人，效果接近。

Q：转账给客户的“核对图”是干什么的？
A：你输入对方给的 TRC20 地址，机器人给你生成一张图。
   让客户核对图上的地址和收款地址一致 —— 防止电脑中木马后
   剪贴板地址被偷偷换掉（这种事很常见，一换钱就没了）。

Q：查地址一直提示“限流”或者查不出来？
A：公共接口用的人多就会被限流。等十几秒再发一次通常就好了。
   经常这样的话，去 trongrid.io 免费申请一个查询 Key，
   私聊发「设置密钥 你的Key」配上去，会宽松很多。
   （那只是查询 Key，不是钱包私钥，不用怕。）

Q：加入了监听，但一直没收到提醒？
A：① 只有【加入监听之后】发生的转账才会推，之前的老账不推
   ② 先去地址簿确认那个地址还在、币种和“只看转入/转出”没设反
   ③ 确认你没有屏蔽这个机器人 —— 被屏蔽了消息发不出去。
      机器人不会因为发不出去就把这笔当成“通知过了”，
      它会一直重试；但你要是没解除屏蔽，它确实送不到。

Q：账单能导出吗？
A：机器人里直接复制文字就行。需要更详细的可以找客服。
