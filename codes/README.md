# codes/ —— 给某一个机器人开小灶

这个目录**平时是空的**。空着 = 什么都没发生，所有机器人行为跟以前一模一样。

只有当**某个客户要一个别人没有的功能**时，才在这里建一个文件：

```
codes/<机器人id>.py
```

机器人 id 在面板上能看到（每个机器人卡片上有，也是 `data/<id>.json` 的文件名）。

---

## ★ 只影响那一个机器人

给 `1923be77` 建了文件，就只有 `1923be77` 的行为会变。
其他机器人（哪怕类型一样）一个字都不受影响。

**不要**为了改一个机器人的行为去改 `runners/` 里的公共代码 ——
那会同时改到所有同类型的机器人。

---

## 能写什么

三个函数，**都是可选的**，写哪个算哪个：

```python
# codes/1923be77.py

def on_start(runner):
    """这个机器人启动时跑一次（重启后也会再跑）"""
    runner.send_to_admins('记账机器人已上线')


def on_message(runner, u):
    """每条消息先过这里。

    返回 True  = 我处理完了，不再走机器人原本的流程
    返回 None / 其他 = 不拦，继续走原本的流程
    """
    msg = u.get('message') or {}
    text = (msg.get('text') or '').strip()
    if text == '今日汇率':
        runner.send(msg['chat']['id'], '1 USDT ≈ 7.25')
        return True


def on_tick(runner):
    """跟着机器人的周期走（记账机器人默认 30 秒一次）"""
    pass
```

`runner` 就是那个机器人本身，能用的东西：
`runner.send(chat_id, 文本)`、`runner.send_to_admins(文本)`、
`runner.bot`（面板上的配置）、`runner.bid`（机器人 id）、`runner.note()`（备注名）。

---

## ★★ 写错了不会把机器人搞挂

这是刻意做的保护 —— 这个文件是手写的，手滑一次不能让一个正在干活的机器人停摆：

| 情况 | 结果 |
|---|---|
| 文件里有语法错 | 记日志，**当作没有这个文件**，机器人照常收发 |
| 文件 import 时就抛异常 | 同上 |
| 某个钩子函数里抛异常 | 记日志，**跳过这一个钩子**，机器人照常收发 |
| 只写了其中一两个函数 | 没写的就当作没有，正常 |

出了什么事都写在 `运行日志.txt` 里，搜「定制文件」就能看到。**日志里一定会带文件名。**

---

## 怎么用

1. 建 `codes/<机器人id>.py`
2. 重启面板（本机重开 exe / 服务器 `systemctl restart tgpanel`）
3. 看 `运行日志.txt`，出现 `加载了定制文件 codes/<id>.py` 就是生效了

★ 改完这个文件**必须重启**才生效（跟改别的代码一样，不会热加载）。
