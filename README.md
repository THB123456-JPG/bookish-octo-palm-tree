# TG 机器人管理面板

统一管理记账、客服、USDT 助手和商城机器人。
新增的每种机器人都使用独立目录与进程，主面板负责管理和权限验证。

## 快速使用

1. 在管理后台添加机器人 Token，选择类型和有效期。
1. 客户私聊机器人发送 `/admin 激活码` 完成绑定。
1. 点击「配置管理」调整设置；具体命令见机器人「使用说明」。

管理员入口为 `/`，商户入口为 `/m`。
客户通过 Telegram 小程序配置自己的机器人，不需要后台密码。

## 功能

| 模块 | 能力 |
| --- | --- |
| 记账 | 入款、下发、汇率费率、账单、统计、群管理、地址查询与监听 |
| 客服 | 私聊转发、回复、操作人管理 |
| USDT 助手 | 地址查询、监听、地址簿、汇率查询 |
| 商城 | 能量、笔数套餐、Telegram 会员及订单管理 |
| 管理后台 | 商户隔离、独立实例、多服务器、容量监控、续费提醒、消息记录 |

记账功能清单见 `功能清单.txt`，客户速查见
`记账机器人_客户使用说明.txt`。
商品是否开放取决于配置及上游能力。

| 文件或目录 | 用途 |
| --- | --- |
| `主程序.py` | 主面板及机器人管理入口 |
| `instance_worker.py` | 单个机器人实例的受管进程 |
| `nodes.py`、`node_worker.py` | 主面板连接及运行服务器控制器 |
| `solo/独立版.py` | 客户自建服务器的独立记账入口 |
| `manager.py`、`bot_instances.py` | 生命周期、实例与状态同步 |
| `core.py` | Telegram 通信、通用权限与消息分发 |
| `panel.py`、`panel_page.html` | 管理及商户面板 |
| `miniapp.py`、`miniapp_page.html` | 客户接口与小程序 |
| `runners/` | 各类机器人业务 |
| `archive.py`、`messages_page.html` | 消息归档与查看 |
| `server_monitor.py`、`runtime_cleanup.py` | 资源监控、容量估算与临时文件清理 |

这些入口属于不同运行模式。同一个 Token 只能由一个位置轮询。
`instances/` 中的源码副本用于客户隔离，不是闲置重复入口。

## 配置和数据

- `config.json`：面板监听、密码、小程序域名等运行配置。
- `bots.json`：机器人、归属、授权与有效期。
- `merchants.json`：商户账号。
- `nodes.json`：运行服务器连接、名称和续费提醒；包含密钥，禁止外传。
- `data/`：账单、设置、消息和图片。
- `instances/<用户名>/`：独立源码、配置、业务数据与运行状态。

部署只更新已验证的源码，保留以上运行配置和数据。
发布工具自动同步已登记的标准实例；发现客户定制差异时停止，避免覆盖。
新增实例从已验证的主源码复制。
不把 Token、密码、私钥或业务数据提交到版本库。

## 服务器监控与保留规则

管理员打开「服务器监控」查看 CPU、内存、磁盘、各实例占用和新增容量估算。
同页可添加服务器、自定义名称、选择新增默认位置；实例表显示所属服务器。
服务器到期和提醒时间按北京时间设置，仅在面板显示，不发送 Telegram 消息。
接入步骤见 [运行服务器接入](运行服务器接入.md)。
资源每 10 秒采样，磁盘分类每 5 分钟统计；离开页面停止浏览器轮询。
估算保留系统余量，低业务量时采用保守预算，不代表生产压测上限。

一个机器人只启动一个业务进程，加入多个群不会额外启动进程。
各类型仅加载自己的业务模块；账单保存在实例 `data/` 的 SQLite 文件中。
消息文字和图片保留 48 小时，账单不随消息过期删除。
过期临时文件、已弃用图片定期清理，在用广告和欢迎图片保留；日志滚动限量。

## 部署

线上服务为 `tgpanel`，工作目录为 `/home/ubuntu/tgpanel`。
使用限定文件的增量发布工具：

```powershell
python _deploy_server.py --dry-run
python _deploy_server.py
```

工具自动核对服务入口、只读 `getMe` 身份和源码哈希，
保存回滚点，完成本地回归、服务器隔离测试及回滚演练，
仅安装差异文件并验证全部登记实例。
详细边界见 [项目规则](AGENTS.md)。

客户自建部署见 [独立部署流程](独立部署流程.md)。
下载安装包不会切换运行位置；切换前先停止另一端的同 Token 实例。
说明及维护工具更新不重启服务；运行源码更新统一停止、安装和恢复服务。
失败会恢复本次已安装的源码，回滚命令由工具输出。
未经明确要求，不提交或推送 GitHub。

## 维护要点

- 金额使用 Decimal；新汇率与费率不能重算历史金额快照。
- 权限由服务端校验，隐藏按钮不能代替接口授权。
- 商城发货结果不明时不要重复执行，先核对订单状态。
- 到期后进入受限状态；停用满 7 天会自动删除，请及时续期。
- 外部查询失败应显示失败，不能当作零余额或成功处理。
